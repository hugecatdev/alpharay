Полезное для демо
- Одобрение — это предложение: «Принять условия» → договор → подписание → выдача. Непринятое за 14 дней предложение истекает.
- Кредит на оборудование без счёта не отправится (шаг «Документы»).
- Мастер заявки с ?mock_fail=1 — разовый сбой БКИ, повторный запрос виден в истории у андеррайтера; с ?mock_fail=2 — БКИ недоступно, после трёх попыток заявка уходит специалисту, а не в отказ.
- Договор подписывается КЭП руководителя: на странице подписания выберите действующий сертификат УЦ ФНС на смоделированном носителе (второй — просроченный, для проверки). Без КЭП — «Подписать кодом подтверждения»: код 4821 показан на экране, SMS не отправляется.
- Выдача смоделирована: в карточке заявки — номер операции PAY-…, реальный платёж не проводится.
- Отказ, отклонение, отзыв или истечение — кнопка «Подать повторно» создаёт новую заявку со ссылкой на прежнюю.
- Сбросить демо-данные: docker compose exec backend python -m app.cli reset-demo, POST /api/demo/reset при DEMO_RESET_ENABLED=true или docker compose down -v.
- Рэй виден, только если на бэкенде задан LLM_API_KEY.
