# Альфа-Будущее Хакатон 2026
## Умный кредитный кабинет предпринимателя

https://github.com/hugecatdev/alpharay 

## Продуктовые преимущества

| Преимущество | Что реализовано |
|---|---|
| Понятная стоимость кредита | Расчёт платежа и переплаты, сравнение сроков |
| Оценка посильности платежа | Учёт действующих кредитов и денежного потока по месяцам |
| Проверка до подачи заявки | Предупреждения о рисках и подсказки по исправлению параметров |
| ИИ-ассистент | Объяснение показателей, расчёт вариантов и подстановка суммы и срока в форму |
| Альтернатива отказу | Предложение меньшей суммы при высокой нагрузке или запрос уточнений |
| Единый путь клиента | Заявка, документы, статусы, принятие условий, демо-подписание и выдача |
| Кабинет банка | Очередь заявок, проверки, факторы скоринга, история решений и статистика |

## Компоненты

- Бэкенд: Python 3.13, FastAPI, SQLAlchemy, Alembic.
- БД: PostgreSQL 17.6.
- Фронтенд: React 18, TypeScript, Vite.
- Docker Compose.

Версии зафиксированы в `backend/poetry.lock` и `frontend/package-lock.json`.

## Запуск

```bash
docker compose up --build
```

Откройте http://localhost:8080. Пароль у всех учёток - `demo`.

## Переменные окружения

Все настройки лежат в `.env` в корне. Для ассистента впишите туда ключ `LLM_API_KEY`, без ключа ассистент скрыт.

## Учётки

| Почта | Что покажет |
|---|---|
